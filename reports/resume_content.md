## ATS-FRIENDLY RESUME BULLET POINTS

### For Data Analyst Role

- Designed and executed an end-to-end data analytics pipeline on **850,000+ IPL delivery records** (2008–2024) using Python (Pandas, NumPy), reducing data inconsistencies by resolving 12 franchise name variants and imputing 97% of missing city records via venue-to-city mapping
- Engineered **15+ derived features** including over phase classification (Powerplay/Middle/Death), batting-first win flag, and per-innings strike rate, enabling advanced phase-wise performance segmentation
- Developed **50+ SQL queries** leveraging window functions (RANK, DENSE_RANK, LAG, LEAD, ROW_NUMBER), CTEs, and subqueries to answer business questions such as toss impact, venue-specific chase success rates, and captain win percentages
- Built a **6-page Power BI dashboard** with drill-through navigation, DAX measures, dynamic titles, and dark professional theme, presenting insights across Team, Player, Venue, Season, and Best XI dimensions
- Designed a **weighted composite scoring model** (normalised across 5 batting + 4 bowling dimensions) to generate an all-time IPL Best XI, demonstrating ability to translate raw stats into actionable franchise recommendations
- Conducted **statistical significance testing** (Chi-Square) to quantify toss advantage (p = 0.05), demonstrating that toss impact is statistically marginal — contradicting common cricket intuition
- Automated the cleaning pipeline as a reusable Python module (`data_cleaning.py`) following PEP8, with docstrings, type hints, and modular functions — enabling one-command re-execution on updated datasets
- Created **31+ publication-quality visualisations** using Matplotlib, Seaborn, and Plotly (including interactive Plotly Express charts), covering Orange Cap race, death-over heatmaps, and consistency scatter plots

## LINKEDIN PROJECT DESCRIPTION

**Title:** IPL Cricket Performance Analysis — End-to-End Data Analytics (2008–2024)

---

🏏 **About the Project**

I built a complete portfolio-grade Data Analytics project on 17 seasons of IPL data — the kind of analysis a franchise analytics team or sports broadcaster would actually use.

**What I built:**

📊 **Data Pipeline** — Cleaned 850,000+ delivery records with Python (Pandas): handled missing cities, normalised franchise name changes, engineered 15+ features including over phases and batting-first flags.

🗃️ **SQL Analysis** — 50+ interview-level queries: window functions (RANK, LEAD, LAG, running totals, moving averages), CTEs, views, and CASE-based pivots answering questions like "Does winning the toss actually matter?"

📈 **30+ Visualisations** — Matplotlib, Seaborn, and Plotly: Orange Cap race, death-over specialist scatter plots, consistency heatmaps, Kohli/Dhoni/Rohit yearly trends.

📉 **Power BI Dashboard** — 6-page dark-theme dashboard with drill-through, DAX measures, dynamic titles, and a Best XI page with weighted player scoring.

🏆 **Best XI Model** — Composite scoring engine weighting runs, average, strike rate, consistency, wickets, economy, and dot ball % — normalised via Min-Max to select an all-time IPL Best XI.

**Key Insight:** The toss advantage is statistically insignificant (p ≈ 0.05, winning ~51.5% of matches). Venue and team quality matter far more than the coin flip.
